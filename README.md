# CPP Practice Programs

A numbered set of C++ practice programs, written to work through the language fundamentals one small exercise at a time.

## What's inside

28 standalone programs, `program-1.cpp` through `program-28.cpp`, each covering a single topic: input/output, operators, conditionals, loops, arrays, functions and simple classes. The set is still growing toward fifty programs.

## Running a program

```bash
g++ program-1.cpp -o program-1
./program-1
```

## Notes

This is a learning collection, not a library — each file compiles on its own and reads from the console where needed.
